# educational-research-skills

教育学SSCI论文快速检索与教学设计工具集，聚焦高等教育中学生体验、女性教育与教育研究方法实践。

## 项目目标
本仓库用于整理教育学研究相关的 AI skill 与研究工作流，当前版本聚焦：
- 高等教育中学生尤其是女生的就读体验
- SSCI 文献快速检索
- 教育学研究选题与文献综述辅助

## 目录说明
- `skills/literature-finder/SKILL.md`：当前核心 skill，面向 SSCI 检索与研究问题梳理
- `README.md`：项目简介

## 使用方式
在支持 skill 的 AI 环境中，直接输入：
- 检索大学女生高等教育中的就读体验
- 检索高等教育中女生归属感研究
- 检索大学生校园支持与学业适应研究
- 检索高等教育中学生体验相关 SSCI 文献

AI 会根据预设规则输出：
- 研究主题总结
- 关键词建议
- 3–5 篇优先推荐文献
- 研究空白与进一步研究方向

## 后续扩展
后续可扩展为：
- `lesson-design-reviewer`：教学设计检查器
- `proposal-helper`：课题申报助手
- `assignment-feedback`：学生作业和论文反馈工具
- `education-search-workflow`：教育研究全流程工作流

## 适用人群
- 高校教师
- 教育学研究者
- 研究生导师
- 课题申报参与者
- 教育学论文写作者

本项目初期聚焦于教育学研究检索能力的 AI 助手构建，可进一步扩展为一个更完整的教育研究工作流平台。
