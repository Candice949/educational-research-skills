# 教育学 SSCI 论文快速检索 Skill

这是一个面向教育学研究者的 AI skill，聚焦于：
- 高等教育中学生尤其是女生的就读体验
- SSCI 文献检索与文献筛选
- 研究议题提炼与文献综述方向设计
- 适合用于论文选题、文献综述、课题申报和研究设计

## 仓库目标
本仓库用于整理与教育学相关的研究工具与 AI 工作流，初期第一版聚焦在 SSCI 文献检索 skill。

## 使用方式
在支持 skill 的 AI 环境中，直接输入：
- 检索大学女生高等教育中的就读体验
- 检索女性学生在高等教育中的归属感和学业适应
- 检索高等教育中学生体验与校园支持研究
- 检索高等教育中女生学习体验相关的 SSCI 文献

AI 会按照预设规则识别主题，输出：
- 研究问题概括
- 关键词建议
- 优先推荐的 3–5 篇文献
- 研究空白与建议方向
